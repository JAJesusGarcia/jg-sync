# JG Sync

**Live BPM Detection & Show Synchronization**

Built for live visuals, lighting and events.

---

JG Sync is a real-time BPM detection and show synchronization application designed for live visual artists, lighting operators and event professionals.

## Project status

JG Sync is currently in its initial development stage.

## Planned features

- Real-time audio capture
- BPM detection
- BPM stabilization
- Visual beat indicator
- Tap Tempo
- Audio device selection
- Windows WASAPI loopback
- Ableton Link synchronization
- Resolume integration
- OSC support
- MIDI Clock support

## Technology

The initial prototype will be developed with Python.

The project may later include a desktop interface and native integrations for audio capture, Ableton Link and show-control protocols.

## Development workflow

Development is organized using dedicated Git branches:

- `main`: stable project state
- `feature/*`: new functionality
- `fix/*`: bug fixes
- `docs/*`: documentation changes
- `refactor/*`: internal code improvements
